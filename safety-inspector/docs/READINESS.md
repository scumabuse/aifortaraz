# Приёмка этапа 7

Проверка выполнена на Windows с чистой SQLite-базой и отдельным каталогом демо-данных. Локальный запуск использовал уже установленные зависимости. Проверены реальные HTTP и WebSocket через прокси Vite, pytest и production-сборка.

| Критерий раздела 11 | Результат и способ проверки |
|---|---|
| Запуск, сид и вход | **Подтверждено локально.** Локальный `scripts/dev.py` поднял Vite и API. `make dev` запускает этот же скрипт. Миграции прошли, вход admin/admin вернул JWT. В базе четыре камеры, 360 исторических инцидентов и 172 800 исторических минутных записей по четырём камерам, плюс текущие записи генератора. `docker compose config` прошёл. Чистый офлайн-перенос образов и контейнерный запуск не выполнялись, поскольку Docker Engine недоступен. |
| Четыре демо-камеры с видео или заглушкой и рамками | **Частично подтверждено.** Подписка на четыре камеры получила кадры метаданных с объектами. Движение нормализованных координат покрыто pytest. Внешний вид видео и анимации в текущей сборке требует браузерной проверки. |
| Симуляция, две вкладки, тревога и звук за 1 с | **Частично подтверждено.** Один критический инцидент получен двумя независимыми WebSocket за **0,357 с** от начала запроса. Тот же ID вернулся в журнале, а дашборд получил обновлённые агрегаты. Проверка toast, красного баннера и аудио в двух открытых вкладках требует браузера. |
| Редактор зон и контракт конфигурации | **Подтверждено на API.** Pytest сохраняет правила и полигоны, проверяет валидацию и ответ GET /api/v1/ingest/config/{camera_id}. Визуальное рисование в текущем прогоне не проверялось. |
| Клиент внешнего ИИ и пауза моков | **Подтверждено для синтетического источника.** Реальный процесс клиента получил конфиг, отправил heartbeat, трек #88, событие HTTP 201 и JPEG через MJPEG-релей. Моки остановились у одной камеры, остальные три продолжили работу. После минуты тишины демо снова работало на всех четырёх. FFmpeg и устройство для прогона дополнительных источников недоступны. |
| Дедупликация и кулдаун | **Подтверждено.** Pytest проверяет HTTP 200 для повторного external_id, HTTP 202 для кулдауна, сохранение квитанций и конкурентные запросы. |
| Статусы, таймлайн и KPI реакции | **Подтверждено на API.** После «принять» зафиксированы acknowledged и время реакции, таймлайн и KPI изменились. Клики по кнопкам текущей сборки визуально не проверялись. |
| Аналитика, план и экспорт CSV | **Подтверждено на API.** Проверены сегодня, смена, 7 и 30 дней, произвольный период. CSV содержит ID проверочного инцидента. Тесты покрывают взвешенный KPI СИЗ, интервалы, загрузку плана и нормализованные координаты. Отображение графиков текущей сборки требует браузера. |
| Печатная форма акта со снимком и PDF | **Частично подтверждено.** HTTP вернул печатную HTML-форму со встроенным JPEG. Pytest проверяет предпросмотр, рамку, экранирование и сохранение акта. Сохранение PDF через диалог печати не выполнялось. |
| Telegram со снимком и работа без сети | **Подтверждено на подставном транспорте.** Проверены multipart sendPhoto, тихие часы, критическое исключение, кулдаун, ответ 429, имитация недоступной сети и итог failed в журнале. Реальную доставку нужно проверить с ботом и тестовым чатом. |
| /about и /wall при 1920×1080 | **Частично подтверждено.** Обе страницы отвечают по HTTP, production-сборка прошла. Метрики и калькулятор покрыты тестами. Локальный браузер отключён в настройках Work, поэтому вид при 1920×1080, полноэкранный режим и ротация визуально не подтверждены. |
| Отсутствие ML и CDN | **Проверено по коду и манифестам.** ML-пакеты отсутствуют, UI и документация Swagger используют локальные ресурсы. Замер сетевых запросов из браузера не выполнялся. |
| README для запуска и подключения ИИ | **Проверено на подготовленной среде.** Команда запуска, вход и запуск внешнего клиента выполнены. README содержит подготовку окружения, перенос Docker-образов, настройку релея, Telegram и ссылки на API. Время установки на второй чистой машине не измерялось. |

Автоматические проверки прошли. 58 pytest-тестов, 8 frontend-тестов, Ruff, ESLint, Prettier, проверка зависимостей Python и production-сборка. Предупреждение pytest относится к устаревающему алиасу AnyIO в Starlette TestClient.

Для завершающей ручной проверки откройте Live и журнал в разных вкладках, включите звук по клику и симулируйте падение. Затем распечатайте акт в PDF, проверьте `/about` и `/wall` на 1920×1080, отправьте тест Telegram и повторите запуск из заранее загруженных Docker-образов на машине без сети.
